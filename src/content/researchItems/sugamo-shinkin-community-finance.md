<h2 id="sec-context"><span class="table-chip">[01]</span>為什麼是巢鴨？</h2>

巢鴨信用金庫位於以「おばあちゃんの原宿」（老奶奶的原宿）聞名的巣鴨地蔵通り商店街周邊。這不僅是地緣上的巧合，更是深層的社會縮影——豐島區高齡化率約 20.8%，且 65 歲以上獨居率為全國市區最高水準。面對日本 2070 年高齡化率將達 39% 的未來，巢鴨信金提供了觀察超高齡社會社區金融的絕佳視角。

<span class="table-chip">TABLE 01</span> **組織概況**

| 項目 | 內容 |
| --- | --- |
| 成立 | 1922年（大正11年）4月4日，創業至今從未合併 |
| 本店 | 東京都豊島区巣鴨2丁目10番2号 |
| 分行數 | 41 店舗 |
| 職員數 | 954 名（2025年3月） |
| 社員（會員）數 | 64,644 名（2025年3月） |
| 預金量全國信金排名 | 第 20 位 |
| 理事長 | 二瓶克博 |

該機構的經營理念奠基於創業精神「相互扶助」與「非營利」，並奉行「年輪經営」的哲學。其企業標語「喜ばれることに喜びを」（以被喜悅為喜悅），更使其成為日本金融機関首家取得「ホスピタリティ」（Hospitality）商標註冊的機構。

<h2 id="sec-business"><span class="table-chip">[02]</span>業務結構：資金從哪來、往哪去</h2>

巢鴨信金的總預金高達 2兆87億日圓，其中流動性預金佔比約 56%，定期性預金佔比約 38%。特別針對高齡客群，其開發了「ゆとり」等高齡者向定期預金，並透過如「夏祭り」、「初夢」等懸賞金付定期預金（年契約額 4,955億日圓）來活絡資金吸收。

<span class="table-chip">FIG 05</span> **放款結構**
<img src="/research/sugamo-loan-mix.svg" alt="業種別：不動產業 40.99%、個人 20.60%、建設業 9.52%、其他業種 28.89%；資金用途：設備資金 65.35%、運轉資金 34.64%" loading="lazy" />
*資料來源：すがもの通信簿2025。作者自繪圖表。*

白話讀法：放款業務高度集中於不動產業與個人住宅，且近三分之二為設備資金，符合傳統信用金庫在地方建設與安居上的角色。

<span class="table-chip">TABLE 02</span> **放款業種與資金用途**

| 分類 | 項目 | 佔比 | 備註 |
| --- | --- | --- | --- |
| 業種別 | 不動產業 | 40.99% | |
| 業種別 | 個人（住宅等） | 20.60% | |
| 業種別 | 建設業 | 9.52% | |
| 業種別 | 其他業種 | 28.89% | 為 100 減去前三者所得之推導值 |
| 資金用途 | 設備資金 | 65.35% | |
| 資金用途 | 運轉資金 | 34.64% | 合計 99.99%，差額為四捨五入 |

值得注意的是，該行預貸率為 47.22%，與業界平均的 47.44% 幾乎完全一致。這顯示資金運用中規中矩，其品牌差異化並非建立在激進的金融商品創新，而是非金融服務與地域黏著度。

<h2 id="sec-financials"><span class="table-chip">[03]</span>五年財務軌跡</h2>

<span class="table-chip">FIG 01</span> **五年財務軌跡**
<img src="/research/sugamo-five-year-financials.svg" alt="2021-2025五年內，預金維持在約2兆圓，貸出金在2023觸底後回升，純利益維持在24至38億日圓間" loading="lazy" />
*資料來源：すがもの通信簿2025。作者自繪圖表。*

白話讀法：預金規模極為穩定，貸出金經歷了 2021/3 至 2023/3 的連續下滑後，在 2023/3 觸底（9,260 億圓），並連續兩年回升。獲利方面，當期純利益穩健，但需注意這背後包含了主動調整的策略操作。

<span class="table-chip">TABLE 03</span> **五年主要指標 (單位：億日圓)**

| 項目 | 2021/3 | 2022/3 | 2023/3 | 2024/3 | 2025/3 |
| --- | --- | --- | --- | --- | --- |
| 總資產 | 22,735 | 22,978 | 21,215 | 21,361 | 21,451 |
| 預金餘額 | 19,987 | 20,007 | 19,933 | 20,011 | 20,088 |
| 貸出金餘額 | 9,788 | 9,325 | 9,260 | 9,357 | 9,487 |
| 經常利益 | 13 | 41 | 52 | 45 | 51 |

深入獲利結構，2025/3 期的コア業務純益達 53億日圓。期間雖認列了 21億日圓的債券売却損（如 104期國債等），但這是趁升息環境換入高利回標的之主動調整。資金運用利回由 0.89% 升至 0.92%，貸出金利回由 1.26% 升至 1.37%，總資金利鞘為 0.15%（前期 0.18%）。由於日本升息，資金調達費用由 0.69億激增至 11.88億（預金利息約 17 倍增），但整體資金運用收益亦由 184億增至 192億。

<h2 id="sec-soundness"><span class="table-chip">[04]</span>健全性與結構性隱憂</h2>

<span class="table-chip">FIG 02</span> **健全性同業對照**
<img src="/research/sugamo-soundness-benchmark.svg" alt="自己資本比率10.95%優於均值；預貸率47.22%貼齊均值；不良債權比率3.35%" loading="lazy" />
*資料來源：すがもの通信簿2025。作者自繪圖表。*

白話讀法：自己資本比率 10.95% 顯著高於國內基準（4%）及東京都內23信金平均（9.58%），體質強健。不良債權比率 3.35% 雖無明確業界平均，但搭配 96.96% 的高保全率，顯示風險控制良好。這是一份讓人「安心」的財務體檢表。

<span class="table-chip">TABLE 04</span> **健全性指標對照 (2025/3)**

| 項目 | 巢鴨信用金庫 | 比較基準 / 備註 |
| --- | --- | --- |
| 自己資本比率 | 10.95% | 國內基準 4% / 東京都內23信金平均 9.58%（2019/3期資料） |
| 預貸率 | 47.22% | 業界平均 47.44% |
| 不良債權比率 | 3.35% | 屬中等水準（個別信金分布約 1%-10%+，查無公開平均） |
| 不良債權保全率 | 96.96% | - |

在債權品質上，開示債權合計為 318億（較前期的 364億持續改善中），其中危険債権 277億。正常債權則高達 9,172億，佔總與信 96.6%。

儘管財務穩健，但結構性課題仍是隱憂。

<span class="table-chip">FIG 03</span> **社員・職員・出資口數的結構性下滑**
<img src="/research/sugamo-membership-index.svg" alt="相對於2021年，社員數降至92.3、職員數降至91.9、出資口數降至94.6" loading="lazy" />
*資料來源：すがもの通信簿2025。作者自繪圖表。*

白話讀法：人員規模與參與度正在穩定流失中，這是極度依賴在地人口紅利的信用金庫模式難以單獨解決的「課題」。

<h2 id="sec-strategy"><span class="table-chip">[05]</span>三支柱、設計策略與台灣的借鏡</h2>

巢鴨信金的實力不僅在帳面數字，更在其營運的正向循環。

<span class="table-chip">FIG 04</span> **三支柱正向循環**
<img src="/research/sugamo-three-pillars-loop.svg" alt="從地域經營、深度理解、高齡服務到品牌差異化的四節點正向循環" loading="lazy" />
*資料來源：作者自繪概念圖。*

白話讀法：透過長期深耕社區與特殊的空間體驗吸引客戶，進而設計貼合高齡者需求的服務，再回饋到更深的地域連結，實證顯示這種非金融投資能直接帶動核心的存貸業務成長。

**三支柱運作：**
1. **地域密著型經營**：除了基礎的訪問式營業（職員騎機車或電動自行車到府服務），自 2009 年起每月 4 日配合とげぬき地蔵縁日舉辦「四の市」在地企業展銷會。此外，S-biz (すがも事業創造センター) 則提供中小企業經營諮詢。
2. **高齡金融與基礎設施**：推動「すがもベテランクラブ」等會員制俱樂部，並與地方政府簽署「見守り協定」，發現高齡者異常即通報行政單位。逢 4 之日更開放非客戶使用店內廁所等設施。全店亦落實無障礙化，設置 AED、簡易筆談器與音聲擴張器。
3. **設計策略與品牌差異化**：自 2009 年起與法國建築師 Emmanuel Moureaux 合作，獨創「色切（shikiri）」概念。

<span class="table-chip">概念示意</span> **色切 (shikiri)**
<img src="/research/sugamo-shikiri-colorband.svg" alt="以色彩作為空間構成元素的色切概念" loading="lazy" />
*註：本圖為作者自繪的概念示意，非建築攝影，未取用任何第三方影像。*

白話讀法：不依賴傳統招牌，而是「以色彩作為空間構成元素」，讓建築本身成為邀請，打造出『用事がなくても入りたくなる』（即使沒有事也想走進去）的空間體驗。其代表作包含志村支店「虹のミルフィーユ」、常盤台支店「leaf」、中青木支店「虹のエアガーデン」。實證成效驚人：新座支店改裝後 1 年內，預金增加約 4 成、貸出增加 1 成。

這套作法能帶給台灣什麼啟發？台灣即將於 2025 年進入超高齡社會，信用合作社或基層金融同樣面臨轉型挑戰。

<span class="table-chip">TABLE 06</span> **台日對照：借鏡與限制**

| 台灣的借鏡方向 | 台灣的移植限制 |
| --- | --- |
| **社區經營的非金融服務**<br>可參考見守り協定與社區活動，從『金融服務提供者』轉為『社區生活夥伴』。 | **資源與規模限制**<br>台灣信合社規模普遍較小，資源有限。 |
| **空間設計作為品牌策略**<br>不必請國際建築師，但可思考『讓人想走進來』的空間改造；投報有實證（新座支店預金+40%）。 | **法規環境不同**<br>台灣信合社受銀行法規範，業務範圍受限。 |
| **高齡金融商品開發**<br>專屬定存、年金管理、資產承繼諮詢；台灣農會與鄉村高齡社區有既有連結的天然優勢。 | **地域特性差異**<br>巢鴨信金位於東京都心，人口密度與消費力與台灣鄉鎮差異大。 |

基層金融不僅是冷冰冰的數字，更是維繫社區社會安全網的重要節點。巢鴨信金百年來的實踐，證明了堅守非營利初衷與追求財務永續不僅不衝突，甚至能互為表裡。
