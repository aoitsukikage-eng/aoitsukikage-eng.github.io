# Public research assets

This directory contains only public-safe, author-created visual assets.

- `beta-risk-comparison.png` — Beta risk comparison chart from the portfolio-risk analysis.
- `beta-sml-analysis.png` — Security Market Line analysis chart from the portfolio-risk analysis.
- `portfolio-optimization-framework.svg` — An original, non-numeric diagram of
  the portfolio-comparison workflow used in the Sharpe-ratio analysis.

The source office files and PDFs are intentionally not distributed. Their
corresponding research records state the safe public alternative or the reason
no original-file download is offered. No third-party image is extracted from
the Sugamo Shinkin report.
