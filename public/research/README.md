# Public research assets

This directory contains only public-safe, author-created visual assets for
inline reading on the research pages.

- `beta-risk-comparison.png` — Beta risk comparison chart from the portfolio-risk analysis.
- `beta-sml-analysis.png` — Security Market Line analysis chart from the portfolio-risk analysis.
- `portfolio-efficient-frontier.svg` — Author-created SVG redrawing the source
  workbook's efficient-frontier and CML coordinates for public reading.
- `sugamo-five-year-financials.svg` — Author-created five-year financial track chart for the Sugamo Shinkin report.
- `sugamo-loan-mix.svg` — Author-created loan mix chart for the Sugamo Shinkin report.
- `sugamo-membership-index.svg` — Author-created membership and staffing index chart for the Sugamo Shinkin report.
- `sugamo-shikiri-colorband.svg` — Author-created abstract shikiri concept diagram for the Sugamo Shinkin report.
- `sugamo-soundness-benchmark.svg` — Author-created soundness benchmark chart for the Sugamo Shinkin report.
- `sugamo-three-pillars-loop.svg` — Author-created three pillars loop diagram for the Sugamo Shinkin report.

Complete report files, source office files, and PDFs are not distributed. The
charts remain page-reading assets and are not offered with download calls to
action. No third-party image is extracted from the Sugamo Shinkin report, but six author-created SVG assets have been added to supplement the structural analysis.
